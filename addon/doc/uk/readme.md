# Wortly

* Автор: Олександр Грищенко
* Версія: 0.0.1 (у розробці)
* Сумісність з NVDA: 2026.1 та новіші версії
* Завантаження: [випуски додатку][1]

Wortly допомагає незрячим і слабозорим людям вивчати німецькі слова з NVDA. Додаток озвучує слово українською мовою, а ви вводите його німецькою. Навчання побудоване на картках та інтервальному повторенні: слова, у яких ви помиляєтеся, повертаються частіше, а слова, які ви добре знаєте, - рідше.

Це рання версія для розробки: функції додатку ще проєктуються і поки недоступні.

## Заплановані функції
* Картки з інтервальним повторенням: слова з помилками повторюються частіше.
* Набори слів, згруповані за темами та рівнями, зручні для вивчення.
* Словникові диктанти, заповнення пропущених літер та інші вправи.
* Вимова німецьких слів, якщо вдасться знайти публічний аудіосервіс.
* Набори слів та аудіо завантажуються з одного сервера, тож дані залишаються синхронізованими.

## Журнал змін
Історію змін для кожної версії додатку опубліковано на [сторінці Releases][1] репозиторію додатку.

## Внесення змін до вихідного коду додатку
Ви можете клонувати цей репозиторій, щоб внести зміни до Wortly.

Вимоги:

* [uv](https://docs.astral.sh/uv/) - керує Python і всіма інструментами розробки додатку;
* [GNU Gettext tools](https://mlocati.github.io/articles/gettext-iconv-windows.html) (`msgfmt` і `xgettext` у `PATH`) - компілюють переклади та створюють шаблон рядків для перекладу.

Виконайте наступні команди з кореня репозиторію:

1. `uv sync` - встановити залежності для розробки;
2. `uv run prek run --all-files` - запустити всі перевірки коду: лінтинг і форматування за допомогою ruff, перевірку типів за допомогою pyright та інші перевірки;
3. `uv run python -m unittest discover -s tests -v` - запустити модульні тести;
4. `uv run scons` - зібрати додаток, створений файл `.nvda-addon` розміщується в корені репозиторію;
5. `uv run scons pot` - створити файл `.pot` з усіма рядками додатку для перекладу (необов'язково).
